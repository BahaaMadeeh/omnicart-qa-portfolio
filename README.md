---

## 📌 Executive Summary

This repository contains the full QA lifecycle deliverables for testing the **OmniCart E-Commerce Platform**. The testing scope includes verifying core customer journeys (Authentication, Catalog Browsing, Shopping Cart, and Checkout) across multiple device form factors, validating underlying RESTful APIs, and auditing database state changes.

---

## 🛠️ Tools & Technologies Used

* **Test Management & Planning:** Markdown, GitHub Repository Artifacts
* **Defect Tracking:** Jira Software (Agile Scrum Workflow)
* **Web & Mobile Testing:** Google Chrome DevTools (Device Mode Viewports)
* **API Testing:** Postman (HTTP GET, POST, PUT, DELETE, Headers, Auth Tokens)
* **Database Verification:** SQLite / DBeaver (Data Persistence Verification)
* **Version Control:** Git, GitHub Desktop
